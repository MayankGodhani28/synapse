Synapse Browser Extension

Save any webpage, text selection, or note directly to your Synapse memory vault with one click.

1 Click the button below to download synapse-extension.zip and unzip it on your computer.
2 Open Chrome (or Edge/Brave) and go to chrome://extensions. Enable "Developer mode" in the top-right corner.
3 Click "Load unpacked" and select the extracted extension folder.
4 Click the Synapse icon in your toolbar, sign in or create an account, and start capturing notes & webpages!
Download Extension (.zip) Version 1.0.0 · Chrome / Edge / Brave MV3

How It Works

The extension saves content to your personal memory scope using your Gmail/email as the primary key. All memories are embedded as vectors and stored in PostgreSQL pgvector for semantic retrieval.

// Extension saves to your personal scope:
POST /memory/add
{
  "user_id": "extension(your@gmail.com)",
  "content": "Selected text or page content",
  "source_type": "webpage",
  "source_url": "https://..."
}
