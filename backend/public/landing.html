The problem

Every AI conversation starts from zero.

Tell a chatbot your name today, and tomorrow it has no idea who you are. The same thing happens to everything you personally save — articles, notes, links — scattered until you can't find them again.

Chat Forgetting

Conversations vanish the moment a session ends. Even frontier models treat repeat users like complete strangers, demanding constant context re-prompting.

"Who am I again?" — every chatbot, every session.

Lost Bookmarks

You save dozens of articles, papers, and code snippets across browser bookmarks, notes apps, and tabs. When you need them, search fails because you can't recall exact keywords.

"I saved this exact solution last month, but where?"
What we provide

One memory backend. Two products.

How it works

From raw content to recalled memory in five steps.

01

Capture

Extension or API receives content

02

Extract

A model decides what's actually worth remembering

03

Embed & Store

Content is vectorized and stored per user

04

Retrieve

A new query is matched by meaning, not keywords

05

Respond

Retrieved facts are woven into the answer

"This is harder than plain search — retrieval finds the same content for everyone; memory tracks what's true for one specific user, and updates when it changes."

For developers

Add memory to your chatbot in two calls.

synapse-integration.js
JavaScript (ES6)
// 1. Before generating a reply — pull relevant memories
const res = await fetch("https://api.synapse.dev/memory/search", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ user_id: "user_123", query: userMessage })
});
const { results } = await res.json();

// 2. After the exchange — store anything new worth remembering
await fetch("https://api.synapse.dev/memory/add", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ user_id: "user_123", content: userMessage, source_type: "chat" })
});
1.

Sign up and generate an API key from your dashboard

2.

Call /memory/search before your LLM call to inject relevant facts into your prompt

3.

Call /memory/add after each exchange to keep memory current

Memory isn't the same thing as search.

Retrieval-augmented generation finds the same chunks for anyone asking a similar question. Memory is different — it tracks what's true for one specific person over time, and knows when a new fact should replace an old one. That's the harder, more useful problem Synapse solves.
